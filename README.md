# MATW Project - Gaza Emergency Impact Dashboard

An interactive executive dashboard and humanitarian reporting studio visualizing key emergency response metrics, relief distributions, infrastructure impacts, and verified field data for the MATW Project Gaza mission.

## Features
- **Executive Overview**: High-impact Bento-grid KPI cards with live stat counters and trend indicators.
- **Detailed Impact Metrics**: Stripe-accented metric cards covering Emergency Relief, Medical Aid, Food Security, Water Sanitation, and Shelter.
- **Interactive Data Studio**: Category filtering, live search, and dynamic field reporting.
- **Export & Share**: Print-ready executive reports, PDF downloads, and social share integration (Open Graph / Twitter Cards).
- **Responsive & Accessible**: Studio-grade typography, dark/light balanced theme, and WCAG AA compliant navigation.

## Quick Start
To run the dashboard locally:
```bash
node server.js
```
Then navigate to `http://localhost:3000` in your browser.
